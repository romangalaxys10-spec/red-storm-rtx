HOW TO PLAY

🎮 Controls

  • Left Click — Select unit/building
  • Left Drag — Box select multiple units
  • Right Click — Move/Attack command
  • WASD or Arrow Keys — Scroll map
  • Ctrl+1-9 — Assign unit group
  • 1-9 — Recall unit group
  • Delete — Sell selected building
  • Space — Center on selected unit

🏗️ Base Building

  • Select Construction Yard to build structures
  • Build Power Plants first — everything needs power
  • Ore Refinery gives you a Harvester to collect credits
  • Barracks train infantry units
  • War Factory builds vehicles
  • Turrets and Pillboxes provide base defense

⚔️ Combat

  • Right-click enemy units/buildings to attack
  • Units auto-attack enemies in range
  • Use combined arms: infantry + tanks for best results
  • Artillery has long range but is weak up close
  • Destroy the enemy Construction Yard to cripple their base

💰 Economy

  • Harvesters automatically seek and return ore
  • Build more Harvesters for faster income
  • Sell buildings for 50% refund
  • Manage power — low power slows production
